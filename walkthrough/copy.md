# Copy rows

Select cells with a drag or Shift+click. Click row numbers to select whole rows. Ctrl+A selects everything.

"Copy CSV" copies the selection with a header row. "Copy JSON" copies an array of objects. Ctrl+C (Cmd+C) copies tab-separated values for pasting into a spreadsheet.

The limit is `tableViewer.maxCopyRows` (100,000 by default).
