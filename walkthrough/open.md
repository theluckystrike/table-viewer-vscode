# Open a data file

Parquet, Excel (`.xlsx`, `.xls`, `.xlsb`, `.xlsm`) and OpenDocument (`.ods`) files open in Table Viewer when you click them in the Explorer.

CSV and TSV files open as text by default. Click the table icon at the top right of the editor, or right-click the file and pick "Open in Table Viewer".

To go back to the text or binary view, use "Reopen Editor With..." from the editor tab menu.
